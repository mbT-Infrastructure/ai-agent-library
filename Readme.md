# AI Agent Library - agents, instructions, prompt and skills

A curated library of opinionated building blocks for AI assistants such as [OpenCode] and [Hermes
Agent].

It provides specialist sub-agents, composable skills for common workflows, ready-to-use prompts and
general instructions so you get more consistent workflows across projects.

## Installation

1. Download from [Releases] and extract.
2. Replace all occurrences of `###AI_NAME###`.
3. Point your agent to it.

[Hermes Agent]: https://hermes-agent.nousresearch.com/
[Releases]: https://github.com/mbT-Infrastructure/ai-agent-library/releases
[OpenCode]: https://opencode.ai/
